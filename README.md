# Hi there, I'm Muhammad Jaidi! 👋

Full-Stack Developer & Informatics Engineering student bridging real-world operational workflows with modern web architectures and self-hosted infrastructure.

### About Me
- 🎓 Studying **Informatics Engineering (Teknik Informatika)** at Universitas Islam Kalimantan Muhammad Arsyad Al-Banjari (UNISKA).
- 💻 Building practical full-stack web applications—from enterprise resource planning (ERP) and inventory systems to academic portals and online retail catalogs.
- 🖥️ Managing 24/7 headless Linux home servers powered by **Armbian, Docker, CasaOS, Tailscale, and Cloudflare Tunnels**.
- ⚡ Leveraging AI-assisted workflows to accelerate full-stack development and system automation.

---

### Featured Projects
- **[HJS ERP](https://hjs-erp.vercel.app)** — Enterprise Resource Planning and operational management web application built with React, TypeScript, and Supabase.
- **[Classport](https://classport.vercel.app)** — Centralized academic and assignment management portal built with Next.js, TypeScript, and Supabase for university cohorts.
- **[GlamourStore](https://glamourstore.my.id)** — Full-stack online retail product catalog built with Next.js, Tailwind CSS, and Supabase.

- **Databases & BaaS:** Supabase, PostgreSQL, MySQL, MongoDB
- **Languages:** TypeScript, JavaScript, Python, C, C++, PHP
- **DevOps & Homelab:** Docker, Linux (Armbian), CasaOS, Tailscale, Cloudflare Tunnels, Git
