# Hi, I'm Muhammad Jaidi

**Production Manager & Full-Stack Web Developer** — building digital systems for real-world operations.

I work across two desks: the production floor and the code editor. While leading daily production workflows at **CV Handayani Jaya Sejahtera** and pursuing a degree in **Informatics Engineering (Teknik Informatika)** at **UNISKA**, I focus on mapping operational bottlenecks first and building practical web applications that teams actually rely on every day.

### What I Focus On
- **Operational & Full-Stack Systems:** Designing end-to-end web apps—from multi-branch inventory and ERP workflows to academic portals and e-commerce catalogs.
- **Self-Hosted Infrastructure & Homelab:** Deploying and maintaining 24/7 headless Linux home servers powered by Docker, Armbian, CasaOS, Tailscale, and Cloudflare Tunnels.
- **Workflow Engineering:** Leveraging modern JavaScript ecosystems and AI tooling to eliminate repetitive manual work.

### Featured Systems
- **[HJS-ERP](https://jaidi.my.id/proyek/hjs-erp)** — Inventory, inter-branch stock mutation, sales, and operational reporting system built for heavy equipment spare parts distribution (`Next.js`, `PostgreSQL`, `Supabase`, `Tailwind CSS`).
- **[ClassPort](https://classport-uniska.vercel.app)** ([Case Study](https://jaidi.my.id/proyek/classport)) — Mobile-first digital classroom and assignment tracker built for university classmates (`Next.js`, `Supabase`, `Tailwind CSS`).
- **[GlamourStore](https://glamourstore.my.id)** ([Case Study](https://jaidi.my.id/proyek/glamourstore)) — Online apparel catalog with product search and direct-to-seller ordering (`Next.js`, `Supabase`, `Tailwind CSS`).
